# sheet-mt-help

Puts the Mythtek sheet's topics into `+help` (`+help sheet`, `+help check`, `+help encounter`, and the staff
and settings topics) by registering the sheet's help object with the `plus-help` librarian, and points the sheet's
"no such switch" message at `+help`. A bridge between [`sheet-mt`](../sheet-mt/) and `plus-help`.
